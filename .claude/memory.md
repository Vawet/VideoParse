# 共享经验索引

随仓库共享的情境经验入口，不是自动 Memory，也不是操作总册。开始任务时匹配具体触发，命中才读详情。没有 Hook 或自动加载保证。

## 文件约定

- 只收录来自真实工作、已复现或经用户确认、非显然、有具体重复触发的经验；写入前查重。治理修改须遵守 CLAUDE.md §5 的授权边界。
- 一条经验一个 `.claude/memory/<trigger-slug>.md`，首段 `## 触发`，正文含来源、适用范围、原因、应用方式及复核/退役条件。
- 本索引每项只写「具体触发 → 详情链接」；删除或合并时同步索引，不留悬空引用。
- 事实留权威源，操作留 Skill；不记录分支、SHA、短期任务状态、验证流水账、密钥或原始数据。
- 经验不能覆盖当前源码或授权边界；使用前核对相关契约是否仍适用。
