# 用 CMIVQA 做问答评测

状态：未实现。来源：2026-10-31 讨论。数据集说明见 [CMIVQA](https://cmivqa.github.io/) 与 [NLPCC2024_MMIVQA](https://github.com/Lireanstar/NLPCC2024_MMIVQA)。

## 目标

用公开的中文教学视频问答，测现有单视频问答的引用是否落在标注的答案时段。不替换 `golden.json`，不评讲义和思维导图。

## 决定

1. 只用带标注的 train 或 dev。比赛期间 test 的正确答案不公开。
2. 只下载标注和中文字幕。问答评测把字幕写入工作区，不读视频文件。
3. 第一刀只保留一个视频：答案时段和至少一条字幕重叠（容差 2 秒，与引用校验一致）的题全部留下。重叠不上的题先丢掉，它们的答案在画面里。
4. 转成和 `golden.json` 相同的字段后，用同一套 `score_answer`。可回答题的 `expect_range` 就是标注的起止秒。
5. 这次不跑出题评测。出题指标仍只对 `golden.json`。

## 非目标

- 不评「先从视频库里检索是哪一条」。
- 不用 BLEU 或另一个模型给长答案打分。
- 不把 EduVidQA、Video-MMLU、Video-MME 混进同一次分数。

## 验收

- 离线检查：每道可回答题的 `expect_range` 都与某条字幕重叠。不要用 `golden.json` 那条「整段字幕完全落在区间内」的断言，CMIVQA 的答案时段常常比一条字幕短。
- 真实模型跑完后，单独报告引用通过率、命中率、步数和重复调用，并写明视频编号和题数。
