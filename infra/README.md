# infra

运行时结构与能力登记的归属目录。对应 enter 的 `infra/`，目前只有骨架，没有注册表。

| 子目录 | 预留用途 | 何时填充 |
| --- | --- | --- |
| `context/` | 由权威输入生成的系统关系视图 | 出现多个服务/外部依赖需要登记上下游时 |
| `references/` | 能力的就绪与验证说明 | 某能力需要记录验证环境与范围时 |
| `release/` | 构建与发布脚本 | 出现真实的部署流程时 |
| `dev-gateway/` | 开发/联调入口 | 出现多环境联调需求时 |

规则：

- 空目录不代表能力存在；先有真实需求和来源，再登记。
- 事实只在权威源维护一份，生成的视图不手改。
- 当前运行时结构见根 `CLAUDE.md` §3。
